# 구해줘 홈즈! 조건 기반 자취방 매물 자동 분석 및 검증기
> **Save My Home: Rule-Based Rental Property Analyzer and Validator** > 1인 가구(대학생 및 사회초년생)를 위한 자취방 조건 자동 필터링 및 안정성 검증 도구입니다.

---

## ## 주요 기능

### 1️⃣ 조건 기반 정답 방 자동 선택
* 입력된 매물 데이터셋을 순회하며 사용자가 설정한 필수 제약 조건(월세 50만 원 이하, 조용한 방음, 안전한 치안)을 모두 충족하는 단 하나의 정답 매물을 자동으로 판별하고 필터링합니다.

### 2️⃣ 깔끔한 요약 표 화면 출력
* 분석된 추천 매물의 세부 정보와 기타 매물들의 명확한 탈락 사유를 줄글이 아닌 가독성 높은 엑셀 형태의 정형화된 표(`pd.DataFrame`)로 변환하여 직관적인 UI로 제공합니다.

### 3️⃣ 예산 오버 및 조건 최종 검사
* 데이터 왜곡이나 시스템 오류로 인한 잘못된 계약을 방지하기 위해, 선정된 방의 실제 월세가 예산 제한선을 초과하지 않았는지 안전장치(`Validation Loop`)를 돌려 교차 검증 후 최종 통과 마크를 부여합니다.

---

## ## 설치 및 실행 방법

### 1. 개발 환경
* **Language:** Python 3.x
* **Library:** Pandas
* **Environment:** Google Colab

### 2. 실행 프로세스
1. 구글 코랩(Google Colab) 환경에서 소스 코드를 로드합니다.
2. 사용자의 예산 한계선 변수(`최대_예산 = 50`) 및 수집한 매물 데이터를 입력합니다.
3. 코드 셀의 **재생(▶) 버튼**을 눌러 프로그램을 실행합니다.
4. 화면에 출력되는 **AI 자동 분석 요약 표**와 **최종 안전성 검증 메시지**를 확인합니다.

---

## ## 테스트 시나리오 결과

### 케이스 A: 정상 작동 (C매물 합격)
* **입력:** 제한 예산 `50`, C매물 데이터(`월세 48`, `방음 우수`, `치안 안전`)
* **출력:** 필터가 C매물을 정확히 선택하고, 교차 검증 단계에서 에러 0개로 `🎉 [최종 통과]` 성공 도장을 화면에 출력합니다.

### 케이스 B: 예산 위반 방어 (B매물 제한)
* **입력:** 제한 예산 `50`, 데이터 입력 오류로 예산을 초과하는 B매물(`월세 75`)이 최종 변수에 강제 대입된 상황
* **출력:** 최종 시스템 검사 로직이 월세 위반을 즉시 감지하여 `❌ [오류 발견]` 경고 문구와 함께 `⚠️ [검증 실패]` 메시지를 띄워 계약을 안전하게 차단합니다.
